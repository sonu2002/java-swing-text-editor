# 📝 Notepad: Java Swing Text Editor

A lightweight **desktop text editor** built with **Java Swing**.

## ✨ Features
- **File:** New, Open and Save (`JFileChooser` + `BufferedReader` / `BufferedWriter`)
- **Edit:** Cut, Copy, Paste and Select All
- Scrollable text area and menu bar

## 🛠️ Tech stack
`Java` · `Swing` · `File I/O`

## 🚀 Run
```bash
cd "Text Editor"
javac TextEditor.java
java TextEditor
```
